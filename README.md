## 安装

1. **服务端**：先装 [Fabric 服务端](https://fabricmc.net/use/server/)，再把 **Carpet** 与本模组的 jar 一起放进服务端的 `mods/` 目录
2. **单人 / 局域网**：客户端也要装 Fabric + Carpet + 本模组——本模组把 Carpet 声明为硬依赖，客户端缺它会直接启动失败

## 常见问题

**开了规则锅还是不结冰？**

四个条件必须同时满足：会下雪的群系、锅在该列地表且头顶露天、该位置方块光 < 10、锅里有足够的水（默认要求满水）。另外**必须有玩家或 Carpet 假人在区块模拟距离内** —— 只加载区块（`forceload`）不会触发检测。用 `/cofdebug data <坐标>` 可以直接看到哪一条不满足。

**为什么默认是关的？**

Carpet 系模组的惯例：所有功能显式开启，避免影响既有的存档与服务器。

**会虚空刷冰吗？**

不会。水是**真的被消耗**的：产出的那一次锅会被清空，和原版水源结冰一样。

**石岸这种群系为什么不结冰？**

结冰跟随原版的**雪线**：判定用 `Biome#getPrecipitationAt(坐标, 海平面)`，它会按高度修正温度。雪线以下原版判为下雨，所以那里不会结冰；锅上下挪动、跨过雪线就会改变结果。

**创造模式测不出水桶/水瓶规则？**

创造模式本来就不消耗物品，所以那两个开关看不出差别。请在生存模式下测试。

**存档里会留下什么？**

一个数据文件 `world/data/cof_cauldron_freezes.dat`（每个维度一份），而且**只记录"正在预热中"的位置** —— 产出、挖掉、取水都会立刻清除记录。从没预热过任何锅的世界不会产生这个文件。


**火药点火为什么点了没反应？**

先确认「可燃火药」是否开启。开启后手持火药右键方块即可像烈焰弹一样点火（并消耗 1 个火药）：能点燃营火/蜡烛、
激活下界传送门、引燃 TNT；音效是"物品被岩浆烧毁"的声音、音量偏小，与真正的烈焰弹不同。关闭时火药不会被消耗，
也不会做任何事。

**傻子转化要多久？中途能打断吗？**

3~5 分钟（与原版治愈僵尸村民同值）。期间职业保持不变、也不能再交互。走远导致区块卸载（或关服）时倒计时会**暂停**
而不是取消，回来继续；**转化中把规则关掉会立即作废这次转化**（倒计时清零、本次加上的力量被移除），重新开启也不会自动恢复，需要重新喂食。

**为什么我关掉「傻子可逆转化」后，已经是傻子的村民还是傻子？**

规则只管"触发"和"过程"，不会回滚已经完成的转化。要把它变回普通村民，给它加上**再生**效果后喂金苹果即可 ——
原来的职业、经验与交易列表都会还原，工作站点认领也会一并恢复。

**关掉「亚历山大图书馆」后，老村民怎么还在卖那三种附魔书？**

规则只影响**新刷出**的交易。已经存在的交易保存在村民自己的交易列表里，关规则不会改变它们 ——
这与「低价村民」的语义一致：只对新生成（含升级新增）的交易生效。

**为什么改完规则，重启后又恢复原样？**

`/carpet <规则名> <值>` 只影响本次运行。要永久保存，用 `/carpet setDefault <规则名> <值>`（写进存档配置），用 `/carpet removeDefault <规则名>` 取消。

**「低价村民」为什么对我的老村民没效果？**

它只影响**之后新刷出**的交易。已经锁定价格的村民不变；只有新生成、或升级产生新档位的交易才会按下限出售。

**关了「正义的伙伴」之后铁傀儡又来打我，是没生效吗？**

是生效的。关掉规则就立即回到原版：附近村民对你的声望 ≤ -100 时，铁傀儡照常来"保卫村庄"。只有在规则开启期间，它才完全不主动攻击你。

**拆掉工作方块后村民没有变成无业？**

先确认「新手村民交易不重置」是否开启：它只拦"村民自己弄丢认领"造成的自发刷新；**玩家拆掉工作方块**仍按原版清零职业（重放方块即可手动重刷）。如果拆掉方块也不清零，说明该规则没有按预期生效。
