# Carpet CoF Addition

**中文** | [English](README_en.md)

## 依赖

本模组为每个 Minecraft 版本各出一个 jar，请下载与你的游戏版本对应的那一个。

| 依赖 | 链接 |
| --- | --- |
| Carpet Mod | [gnembon/fabric-carpet](https://github.com/gnembon/fabric-carpet) |
| Fabric Loader | [fabricmc.net/use/installer](https://fabricmc.net/use/installer/) |
| Java 21 | [Oracle 官方下载（Java 21）](https://www.oracle.com/java/technologies/downloads/#java21) |

Carpet 请选与你 Minecraft 版本一致的最新发布版，Fabric Loader 用该版本的主流版本即可；Java 需要 21。

> **12 个版本功能行为一致**，没有功能降级；每个 jar 只服务于它自己那个 MC 版本。

## 下载

本模组从 [Releases](../../releases) 下载：选文件名里 `mc` 后面那个版本与你游戏**完全一致**的 jar。

Java 21 只有**自建服务端**或**手动指定 Java 启动**时才需要自己装：官方启动器会自带运行时，HMCL / PCL 这类启动器也能自动下载。
